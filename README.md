# UNO Party Online 🃏

เกมการ์ดแนว UNO แบบ Real-time Multiplayer เล่นผ่านเว็บได้ 2–8 คนพร้อมกัน (รองรับทั้งมือถือและคอมพิวเตอร์) สร้างห้องด้วย **Room Code 4 ตัวอักษร** พร้อม **บอท AI**, แชตในห้อง, อีโมจิ, ระบบตะโกน UNO! / จับได้ (+2), และเสียงเอฟเฟกต์

## ฟีเจอร์หลัก
- **สร้างห้องด้วย Room Code 4 ตัว** พร้อมปุ่มคัดลอกลิงก์ชวนเพื่อน (`?room=XXXX`)
- **เล่นได้ 2–8 คน** + หัวหน้าห้องกดเพิ่ม/ลบ **บอท AI** เติมให้ครบโต๊ะได้
- **กติกา UNO ครบชุด (108 ใบ):** `+2`, `+4`, ข้ามตา (`⊘`), ย้อนทิศ (`⇄` รวมถึงกติกา 2 คน = เล่นต่อทันที), เปลี่ยนสี (`★`), สลับโหมดต่อการ์ด `+2/+4` สะสมได้ (Stacking)
- **ปุ่มตะโกน UNO! และปุ่มจับได้ (+2):** ถ้าเหลือ 1 ใบแล้วลืมกด UNO เพื่อนสามารถกดจับเพื่อลงโทษจั่ว +2 ได้
- **ระบบเชื่อมต่อกลับอัตโนมัติ (Auto-Reconnect):** เน็ตหลุดชั่วคราวมีเวลา 45 วินาทีกลับเข้าห้องเดิมได้
- **Server-Authoritative:** ตรวจกติกาและจัดการสำรับการ์ดฝั่งเซิร์ฟเวอร์ ป้องกันการโกง

## วิธีรันทดสอบบนเครื่อง
```bash
npm install
npm start
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## วิธีนำขึ้นออนไลน์ฟรี (ให้เพื่อนเข้าผ่านลิงก์ได้ทันที)

### วิธีที่ 1: Render.com (แนะนำ — ฟรี + มี `render.yaml` พร้อมแล้ว)
1. นำโฟลเดอร์ `uno-party-online` ขึ้น GitHub repository ของคุณ
2. เข้า [render.com](https://render.com) → กด **New +** → เลือก **Blueprint** (หรือ **Web Service**)
3. เชื่อมต่อ repository นี้ — Render จะอ่านค่าจาก `render.yaml` ให้อัตโนมัติ (`npm install` / `npm start`)
4. รอ Deploy ~1–2 นาที จะได้ลิงก์ `https://uno-party-online.onrender.com` ส่งให้เพื่อนเข้าเล่นพร้อมกันได้เลย!

### วิธีที่ 2: Railway.app
1. นำโค้ดขึ้น GitHub แล้วเข้า [railway.app](https://railway.app) → **New Project → Deploy from GitHub Repo**
2. Railway จะใช้ `railway.json` และเปิดพอร์ตให้อัตโนมัติ → กด **Generate Domain** เพื่อรับลิงก์ออนไลน์
